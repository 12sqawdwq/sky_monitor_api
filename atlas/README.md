# 星海图志 · Sky Atlas

多尺度的网页星图。从观测者头顶的星空出发，依次经过太阳系、奥尔特云、恒星邻域、银河系、本星系群、拉尼亚凯亚超星系团，一直到可观测宇宙的边界。镜头视距从约 0.4 天文单位到 4000 亿光年，跨约 16 个数量级。另有一个仿照 Star Walk 的“今晚星空”视图，显示观测者所在位置的真实天空。

线上地址：**https://sky.eunoia.top/**（星图就是首页；“今晚星空”在 `/tonight`，尺度巡游在 `/tour`）。

技术栈：Vite 7、TypeScript、three.js 0.180。没有使用 UI 框架，所有界面都是原生 DOM。

## 运行

```bash
cd atlas
npm install
npm run dev    # http://localhost:5173 ，/sky-api 代理到 https://sky.eunoia.top
npm run build  # tsc 类型检查 + vite 构建，产物在 dist/
```

`public/data/` 里已经带有烘焙好的数据，下载后可以直接运行。如需重新生成：

| 命令 | 输入 | 输出 |
|---|---|---|
| `npm run data` | HYG v3 星表 CSV。默认读取 `../data/raw/hygdata_v3.csv`，即后端 `python scripts/download_hyg.py` 下载的位置；也可以把路径作为参数传入 | `stars.bin`（约 10.9 万颗恒星：三维坐标、绝对星等、色指数）、`named.json`（带中文名的亮星） |
| `node scripts/build-constellations.mjs <lines.json> <constellations.json>` | d3-celestial 0.7.35 的西方星座数据 | `constellations.json`（89 个星座，743 段连线） |
| `node scripts/build-mansions.mjs <lines.cn.json> <constellations.cn.json>` | d3-celestial 0.7.35 的中国星官数据 | `mansions.json`（二十八宿的星官连线和距星） |

## 三维宇宙图谱（`/`）

- **浮动原点**：镜头始终环绕场景原点，每一层按 `layer.origin - focus`（float64）平移。从行星尺度一直到宇宙学尺度，画面都不会出现精度抖动。
- **恒星**：按镜头所在位置实时计算视星等。飞离太阳后，熟悉的星座会被“拉开”。
- **星座连线**：太阳系附近的尺度上，主要星座（黄道十二星座加二十个导航星座）的连线画在恒星的真实三维位置之间。镜头飞出约 8 光年后连线淡出。
- **尺度阶梯和档案**：左侧阶梯可以一键飞往各个尺度。点选天体打开档案卡，可以“在今晚天空中查看”。
- **配色**：只用暖色调（羊皮纸、铜、琥珀、余烬），不用蓝紫色。

## 今晚星空（`/tonight`）

观测者视角，带地平线山脊、方位、银河光带，天色随太阳高度变化，月相的亮面朝向太阳。

- **交互**：拖拽环顾，滚轮或双指缩放。时间胶囊可以前后拨动，也可以加速播放。手机上可以开启陀螺仪，直接对准天空。
- **信息卡**：点击天体弹出，内容包括高度、方位、星等等级、升起/中天/落下时间。可以一键“在宇宙中查看”。
- **星座**：右上角按钮在“主要 / 全部 / 关”之间切换。黄道星座用琥珀色加亮。
- **黄道**：
  - ±8° 的黄道带：中线发光，边缘为虚线。
  - 太阳所在的宫用暖色衬底。
  - 每 15° 一个节气刻度，每 30° 一个宫界。
  - 十二宫和二十四节气的标注沿黄道方向排列。太阳当前所在的宫和节气会高亮。
  - 太阳的信息卡显示黄经、所在宫、当前节气和下一个节气的日期。
- **二十八宿**：
  - 打开后，用朱砂色画出二十八宿的星官连线，并在黄道上标出各宿的边界（过距星的赤经圈）。
  - 视野拉远时显示四象名称（东方苍龙、北方玄武、西方白虎、南方朱雀）。
  - 月亮所在的宿会高亮；月亮的信息卡显示“月宿”，太阳的信息卡显示“日躔”（太阳所在的宿及宿内度数）。
  - 打开二十八宿时，西方星座连线自动减淡一半。
- **星光**：按亮度等级分别呈现：
  - **大小和眩光**：越亮的星越大；零等星和负等星带光晕和衍射十字芒。
  - **颜色**：按色指数着色。亮星颜色饱和，暗星偏灰白，因为人眼的视锥细胞只对亮光敏感。
  - **大气效应**：地平线附近有大气消光，星光变暗。
  - **闪烁**：每颗星有自己的闪烁节奏。越接近地平线，闪烁越强；低空的亮星还会出现彩色闪烁，比如冬夜低空的天狼星。系统开启“减少动态效果”时，闪烁会减弱。
- **今晚推荐**：来自星图后端 `POST /sky/chart`（带 `time_utc`），8 秒超时。后端不可达时改用本地计算，并在界面上标明数据来源。

## 数据来源与可信度

| 内容 | 来源 | 性质 |
|---|---|---|
| 恒星 | HYG v3 星表（CC BY-SA 2.5） | 实测 |
| 行星、探测器 | J2000 平均轨道根数 + 开普勒方程 | 近似（角分级） |
| 太阳、月亮 | 低精度解析公式 | 约 0.3° |
| 星座、二十八宿连线 | d3-celestial（BSD-3，见 `public/data/CONSTELLATIONS-LICENSE.txt`） | 实测位置 |
| 星云、星团、近邻星系 | 手工整理的坐标 + 文献距离 | 位置实测，形态示意 |
| 银河系、宇宙网 | 程序生成（4 条对数螺旋臂，螺距 13°，中央棒 27°） | 示意模型 |

## 部署

生产环境把前端和后端放在同一个域名下，nginx 的配置示例见仓库里的 `deploy/nginx.example.conf`（`# sky-atlas` 段）：

| 路径 | 处理方 |
|---|---|
| `/`、`/tonight`、`/tour` | 前端 `index.html`（子功能是深链接） |
| `/assets/`、`/data/` | 前端静态资源 |
| 其余路径（`/sky/*`、`/wiki`、`/docs`、`/health` 等） | FastAPI 后端 |

生产构建（`.env.production`）把 `VITE_SKY_API_BASE` 设为空，直接请求同域的 `/sky/chart`，所以不需要配置 CORS。

发布时整体替换静态目录，并保留上一版用于回滚：

```bash
npm run build
cd dist && tar czf - . | ssh <server> 'set -e; cd /var/www/sky-atlas; rm -rf site.new; mkdir site.new; \
  tar xzf - -C site.new --no-same-owner; chmod -R a+rX site.new; rm -rf site.prev; mv site site.prev; mv site.new site'
```

新增子功能的步骤：在 `src/main.ts` 的路由里加一个名字，再把它加进 nginx 的 `location ~ ^/(tonight|tour)/?$`。注意不要和后端已有的路径重名，可以对照 `/openapi.json` 检查。

## 结构

```text
scripts/            数据烘焙：恒星、星座、二十八宿
src/core/           坐标转换、浮动原点镜头、着色器材质、单位
src/layers/         太阳系、恒星、星座、银河系、星系、宇宙网、视界、经纬网
src/data/           天体档案、星座中文名、黄道 / 节气 / 二十八宿、后端 API、观测者位置
src/sky/            今晚星空：天文计算（astro）、天空场景（scene）、交互界面（skyview）
src/ui/             标注、档案面板、搜索、尺度阶梯
```
