GPS Sky Chart Backend · FastAPI · HYG · Skyfield

把当前位置切成一张可调用的星图

星海图志的星图后端：接收 GPS 经纬度和时间，返回此刻地平线以上值得看的亮星、行星、星团、星云与星系， 并附上可以直接绘制极坐标星图的相对坐标和给大语言模型用的中文观测语料。

01系统架构

后端把稳定的星表数据、实时天文计算和平台可调用的 API 分层处理。大语言模型不做天文计算，只读取结构化结果再组织语言。

前端与工具星海图志 · 灵珠

同一个域名下，首页 星海图志 是三维宇宙图谱和“今晚星空”，它的“今晚推荐”直接调用这里的 /sky/chart；其余路径由 FastAPI 提供。

02星表与筛选逻辑

目标是真实的观测体验：默认只返回高度够、亮度够、辨识度高的天体，而不是把原始星表整个丢给模型。

Stars

恒星

来自 HYG Database，保留常用名、赤经赤纬、视星等、距离、光谱型和星座。默认视星等 ≤ 3、高度角 ≥ 15°。

Planets

太阳系行星

Skyfield + DE421 计算。行星的门槛放宽：只要在地平线以上就进入候选，方便回答“今晚能不能看到土星”。

Deep Sky

深空天体

内置知名星团、星云、星系清单，亮度阈值放宽到 9 等，重点覆盖 M31、M42、M45 等高辨识目标。

03交互演示

04核心 API

灵珠平台已验证的调用方式是 GET Query 参数。OpenAPI 的 servers 固定为域名，避免平台把服务地址识别成 IP。

GET /sky/chartcurl
curl "https://sky.eunoia.top/sky/chart?latitude=31.2304&longitude=121.4737"
只传 latitude 和 longitude 即可。后端默认高度角 15°、恒星 3 等、深空天体 9 等，并自动控制数量。完整参数见 API 调用手册，或在 Swagger 里直接试。

06工程日志

  1. V0

    星表后端搭建

    FastAPI 服务、SQLite 星表、HYG 导入、基础健康检查和亮星查询。

  2. V0.2

    天文计算接入

    引入 Skyfield / Astropy，按 GPS 坐标和时间计算地平坐标，输出可见天体。

  3. V0.3

    星图 API 优化

    扩展深空天体和行星逻辑，增加 chart_x、chart_y、chart_radius，便于前端绘制极坐标星图。

  4. V0.3.1

    灵珠平台适配

    OpenAPI servers 固定为 https://sky.eunoia.top，GET 参数兼容 latitude / longitude。

  5. 2026-10

    星海图志前端

    首页换成三维宇宙图谱和今晚星空（黄道、二十八宿、中英双语），Wiki 与状态页统一为同一套配色。
