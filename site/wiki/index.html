把当前位置切成一张可调用的星图

Lingzhu Sky Assistant 是面向灵珠平台和语音助手的天文后端服务。它接收 GPS 经纬度和时间， 输出当前地平坐标系下可见的亮星、行星、知名星团、星云与星系，并给出适合前端绘制星图的相对坐标。

星表与筛选逻辑

当前版本以真实观测体验为目标，默认只返回高度角足够、亮度可见、识别度高的天体，避免把星表原始数据直接倾倒给模型。

Stars

恒星

来源于 HYG Database，保留常见名称、赤经赤纬、视星等、距离、光谱型和星座信息。默认筛选视星等小于等于 3 等、高度角大于等于 15 度。

Planets

太阳系行星

通过 Skyfield 和 DE421 星历计算，行星优先级被放宽，只要在地平线上方就可进入候选结果，适合回答“能否看到金星/火星/土星”。

Deep Sky

深空天体

内置知名星团、星云、星系清单。深空天体默认亮度阈值放宽到 9 等，重点覆盖 M31、M42、M45 等高识别目标。

核心 API

灵珠平台当前已验证通过的调用方式是 GET Query 参数。OpenAPI schema 的 server 已固定为域名，避免平台把服务地址识别为 IP。

GET /sky/chart
curl "https://sky.eunoia.top/sky/chart?latitude=31.2304&longitude=121.4737"

只传 latitude 和 longitude 即可。后端会默认使用高度角 15 度、恒星 3 等、深空天体 9 等和智能数量控制。
