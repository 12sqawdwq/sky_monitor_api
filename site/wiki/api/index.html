01灵珠平台配置

用“导入工具”时优先导入 OpenAPI；手动创建工具时按下面三步填写。

  1. 导入地址：URL 和原始数据框都填 https://sky.eunoia.top/openapi.json。
  2. 选择接口：选 GET /sky/chart，平台会把坐标作为 Query 参数传入。
  3. 保留参数：只保留 latitude 和 longitude 两个必填参数，不要把 User-Agent 当作用户输入。
线上 OpenAPI 的 servers 已固定为 https://sky.eunoia.top。如果平台仍显示 IP，多半是旧的导入缓存，删除工具后重新导入即可。

02请求参数

GET 调用时参数放在 Query 中。后端兼容字符串形式的数字，但建议平台侧配置为 Number。

参数必填类型说明
latitude是NumberGPS 纬度，-90 到 90。上海约 31.2304。
longitude是NumberGPS 经度，-180 到 180。上海约 121.4737。
time_utc否StringUTC 时间，如 2026-05-16T03:15:00Z。不传则用当前时间。
total_limit否Number返回天体数量，默认 28，范围 8 到 60。
min_altitude_deg否Number恒星和深空天体的最低高度角，默认 15。

03响应结构

顶层字段为 sky_chart，其中 objects 是可以直接绘制星图的天体数组。chart_radius 为 0 表示天顶、1 表示地平线；chart_x 向东为正，chart_y 向北为正。

response.json节选
{
  "sky_chart": {
    "observer": {"lat": 31.2304, "lon": 121.4737},
    "time_utc": "2026-05-16T03:35:45Z",
    "coordinate_system": {
      "horizontal": "azimuth_deg: 0 north, 90 east, 180 south, 270 west",
      "chart_projection": "polar_azimuthal_horizon"
    },
    "counts": {"star": 12, "planet": 4, "deep_sky": 6},
    "objects": [
      {
        "category": "star",
        "display_name": "五车二",
        "azimuth_deg": 49.03,
        "altitude_deg": 62.3,
        "magnitude": 0.08,
        "chart_x": 0.2324,
        "chart_y": 0.2018,
        "chart_radius": 0.3078
      }
    ]
  }
}

04调用示例

上海，当前时间

curl "https://sky.eunoia.top/sky/chart?latitude=31.2304&longitude=121.4737"

限制返回数量

curl "https://sky.eunoia.top/sky/chart?latitude=31.2304&longitude=121.4737&total_limit=8"

指定观测时间

curl "https://sky.eunoia.top/sky/chart?latitude=31.2304&longitude=121.4737&time_utc=2026-10-20T14:00:00Z"

POST 方式

curl -X POST "https://sky.eunoia.top/sky/chart" \
  -H "Content-Type: application/json" \
  -d '{"latitude":31.2304,"longitude":121.4737}'

05全部接口

接口说明
GET/POST /sky/chart此时此地的可见天体与星图坐标（主接口）
GET/POST /sky/facts天体知识条目
POST /sky/ask观星问答
GET /stars/bright亮星列表，?limit=20
GET /stars/search按名称查恒星，?name=Sirius
GET /catalog/stats星表统计
GET /reasoning/corpus生成 reasoning_context 用的中文观测语料
GET /health健康检查（JSON）；可视化版本见 服务状态
