星图 API 调用手册

面向灵珠平台、网页、脚本和其他客户端的调用说明。最小请求只需要 GPS 纬度和经度， 服务会返回当前地点可见的亮星、行星和知名深空天体。

OpenAPI JSON Swagger UI Health
quick-start.sh 
curl "https://sky.eunoia.top/sky/chart?latitude=31.2304&longitude=121.4737"

灵珠平台配置

如果用“导入工具”，优先导入 OpenAPI；如果手动创建工具，按下面字段填写。

1

导入地址

在 URL 和原始数据框中填：

https://sky.eunoia.top/openapi.json
2

选择接口

选择 GET 版本，便于平台把坐标作为 Query 参数传入。

GET /sky/chart
3

保留参数

只保留 latitude 和 longitude 两个必填参数。不要把 User-Agent 当作用户输入。

当前线上 OpenAPI 的 servers 已固定为 https://sky.eunoia.top。如果平台仍显示 IP，多半是旧导入缓存，删除工具后重新导入即可。

请求参数

GET 调用时，参数通过 Query 传入。后端兼容字符串数字，但建议平台侧配置为 Number。

参数 必填 类型 说明
latitude 是 Number GPS 纬度，范围 -90 到 90。例如上海约为 31.2304。
longitude 是 Number GPS 经度，范围 -180 到 180。例如上海约为 121.4737。
time_utc 否 String UTC 时间，例如 2026-05-16T03:15:00Z。不传则使用当前时间。
total_limit 否 Number 返回天体数量，默认 28，范围 8 到 60。
min_altitude_deg 否 Number 恒星和深空天体最低高度角，默认 15。

响应结构

返回值顶层字段为 sky_chart，其中 objects 是可绘制星图的天体数组。

response.json 
{
  "sky_chart": {
    "observer": {"lat": 31.2304, "lon": 121.4737},
    "time_utc": "2026-05-16T03:35:45Z",
    "coordinate_system": {
      "horizontal": "azimuth_deg: 0 north, 90 east, 180 south, 270 west",
      "chart_projection": "polar_azimuthal_horizon"
    },
    "counts": {"star": 12, "planet": 4, "deep_sky": 6},
    "objects": [
      {
        "category": "star",
        "display_name": "五车二",
        "azimuth_deg": 49.03,
        "altitude_deg": 62.3,
        "magnitude": 0.08,
        "chart_x": 0.2324,
        "chart_y": 0.2018,
        "chart_radius": 0.3078
      }
    ]
  }
}

调用示例

上海当前位置

curl "https://sky.eunoia.top/sky/chart?latitude=31.2304&longitude=121.4737"

限制返回数量

curl "https://sky.eunoia.top/sky/chart?latitude=31.2304&longitude=121.4737&total_limit=8"

POST 方式

curl -X POST "https://sky.eunoia.top/sky/chart" \
  -H "Content-Type: application/json" \
  -d '{"latitude":31.2304,"longitude":121.4737}'
